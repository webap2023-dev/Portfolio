# Akrem Ben Amor — Industrial Maintenance Portfolio

A static, responsive portfolio website prepared for GitHub Pages. Includes English, French and Arabic language switching, animated name treatment, animated electronic/circuit background, original portrait, SMLT test-bench project photo, experience, education, skills, commonly used industrial software references, and LinkedIn contact.

## Files
- `index.html` — website structure and content
- `style.css` — responsive design, neon industrial look and animations
- `script.js` — language switching and mobile navigation
- `assets/akrem-ben-amor.jpg` — supplied portrait
- `assets/smlt-test-bench.png` — supplied SMLT test-bench project image

## Publish directly with GitHub Pages
1. Create a GitHub repository (e.g. `akrem-portfolio`).
2. Extract this ZIP and upload **all files and folders** to the repository root. Keep the `assets` folder beside `index.html`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site and open the URL it provides.
